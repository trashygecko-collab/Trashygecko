LEVELCODE FÜR DAS SPIEL

Der Code passt direkt in den const LEVELS = [ ... ];-Bereich deiner DURST-Spielversion. Jede Zeile hat genau 20 Zeichen, jedes Level genau 12 Zeilen.

LEVEL AUS CODE LADEN

Hier kannst du einen einzelnen Level-Block im JSON-Format einfügen. Beispiel: {"name":"Level 1","map":["...12 Zeilen..."]}. Das Laden ersetzt das gerade ausgewählte Level.
