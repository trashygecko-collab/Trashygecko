HTML & CSS – TEXT

Hier geht es hauptsächlich um Text: Formatierung, Farben, Größe, Schriftarten, Abstände und weitere wichtige CSS-Befehle.

HTML – Text formatieren

Fett

Fetter Text
<b>Fetter Text</b>
Macht den Text fett.

Kursiv

Kursiver Text
<i>Kursiver Text</i>
Macht den Text kursiv.

Unterstrichen

Unterstrichener Text
<u>Unterstrichener Text</u>
Unterstreicht den Text.

Durchgestrichen

Durchgestrichener Text
<s>Durchgestrichener Text</s>
Zeigt eine Linie durch den Text.

Hochgestellt

102
10<sup>2</sup>
Setzt Text hoch. Zum Beispiel für Quadratmeter oder Potenzen.

Tiefgestellt

H2O
H<sub>2</sub>O
Setzt Text tiefer. Wird häufig bei chemischen Formeln verwendet.

Markieren

Das ist markierter Text.
<mark>markierter Text</mark>
Hebt einen Textbereich hervor.

Zeilenumbruch

Erste Zeile
Zweite Zeile
Erste Zeile<br>Zweite Zeile
<br> beginnt eine neue Zeile.

CSS – Textfarben

Farbname

Roter Text
color: red;
Ändert die Textfarbe auf Rot.

Springgreen

Grüner Text
color: springgreen;
Du kannst viele englische Farbnamen verwenden.

HEX-Farbe

Cyaner Text
color: #00ffff;
HEX-Farben werden mit einem # und sechs Zeichen angegeben.

RGB

Blauer Text
color: rgb(0, 191, 255);
RGB steht für Rot, Grün und Blau.

RGBA

Halbtransparenter Farbwert
color: rgba(255, 20, 147, 0.5);
Der letzte Wert bestimmt die Transparenz. 0 = unsichtbar, 1 = vollständig sichtbar.

CSS – Schriftgröße

font-size

Kleiner Text
Normaler Text
Großer Text
Sehr großer Text
font-size: 30px;
Mit font-size bestimmst du die Größe des Textes.

CSS – Schriftarten

font-family

Arial – Beispiel
Times New Roman – Beispiel
Courier New – Beispiel
Monospace – Beispiel
font-family: Arial, sans-serif;
Bestimmt, welche Schriftart verwendet wird.

CSS – Schriftstärke

font-weight

Normal
Fett
Dünn
font-weight: bold;
Bestimmt, wie dick die Schrift dargestellt wird.

CSS – Schriftstil

font-style

Normaler Text
Kursiver Text
font-style: italic;
italic macht den Text kursiv.

CSS – Textdekoration

text-decoration

Unterstrichen
Durchgestrichen
Keine Dekoration
text-decoration: underline;
text-decoration: line-through;
text-decoration: none;
Damit kannst du Linien über, unter oder durch den Text setzen.

CSS – Text ausrichten

text-align

Linksbündig
Mittig
Rechtsbündig
text-align: center;
Bestimmt die horizontale Ausrichtung des Textes.

CSS – Zeilenabstand

line-height

Erste Zeile
Zweite Zeile
Dritte Zeile
line-height: 2;
Bestimmt den Abstand zwischen den Textzeilen.

CSS – Buchstabenabstand

letter-spacing

Mehr Abstand zwischen Buchstaben
letter-spacing: 6px;
Vergrößert oder verkleinert den Abstand zwischen einzelnen Buchstaben.

CSS – Wortabstand

word-spacing

Mehr Abstand zwischen den Wörtern
word-spacing: 15px;
Verändert den Abstand zwischen einzelnen Wörtern.

CSS – Groß- und Kleinschreibung

text-transform

Dieser Text wird großgeschrieben
DIESER TEXT WIRD KLEINGESCHRIEBEN
jedes wort bekommt einen großen anfangsbuchstaben
text-transform: uppercase;
text-transform: lowercase;
text-transform: capitalize;
Verändert die Darstellung von Groß- und Kleinbuchstaben.

CSS – Textschatten

text-shadow

Text mit Schatten
text-shadow: 3px 3px 5px black;
Erzeugt einen Schatten hinter dem Text.

CSS – Neontext

Neon-Effekt

NEON TEXT
color: cyan;
text-shadow: 0 0 5px cyan, 0 0 10px cyan, 0 0 20px cyan;
Mit mehreren Textschatten kann ein Leuchteffekt erzeugt werden.

CSS – Hintergrund hinter Text

background-color

Text auf blauem Hintergrund
background-color: darkblue;
Ändert die Hintergrundfarbe eines Elements.

CSS – Abstand um Text

padding

Text mit Abstand rundherum
padding: 12px;
padding erzeugt Abstand zwischen dem Inhalt und dem Rand eines Elements.

CSS – Mehrere Befehle kombinieren

Mehrere Eigenschaften gleichzeitig

Schöner grüner Text
color: springgreen;
background-color: #111111;
font-size: 30px;
font-weight: bold;
padding: 12px;
Du kannst beliebig viele CSS-Eigenschaften miteinander kombinieren.

HTML – Einzelnen Text einfärben

<span>

Normaler Text und roter Text im gleichen Satz.
Normaler Text <span style="color:red;">roter Text</span>
Mit span kannst du einen einzelnen Teil eines Textes gezielt formatieren.

CSS – Links gestalten

Linkfarbe

Beispiel-Link
a {
  color: cyan;
  text-decoration: none;
}
Mit CSS kannst du Farbe, Unterstreichung und andere Eigenschaften von Links verändern.

Hover

Maus über diesen Link bewegen
a:hover {
  color: yellow;
}
:hover bestimmt, wie ein Element aussieht, wenn sich die Maus darüber befindet.

Die wichtigsten Befehle

color: red;
font-size: 24px;
font-family: Arial;
font-weight: bold;
font-style: italic;
text-decoration: underline;
text-align: center;
line-height: 1.5;
letter-spacing: 2px;
word-spacing: 5px;
text-transform: uppercase;
text-shadow: 2px 2px 5px black;
background-color: black;
padding: 10px;
Diese Befehle decken einen großen Teil der normalen Textgestaltung mit CSS ab.
