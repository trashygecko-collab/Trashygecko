Einbinden


Stylesheets im Head festlegen

<head>
<title>Stylesheet einbinden</title>
<style>
h1 { color: green; }
</style>
</head>



Eigenschaften einem Element direkt zuzuweisen

<body>
<h1 style="text-align: center; text-decoration: underline;">
Formate direkt festlegen
</h1>
</body>



Stylesheets in separate Dateien

<head>
<title>externe Stylesheet Datei einbinden</title>
<link type="text/css" rel="stylesheet" href="externestylesheet.css">
</head>


CSS-Dateien bestehen aus reinem Text, als Dateiendung hat sich „.css“ durchgesetzt.
