cmd

Liste der Windows-Befehle
CMD steht für Command (zu Deutsch: Befehl). Das Eingabefenster, in das die Befehle eingegeben werden, wird als Eingabeaufforderung bezeichnet.
Start, Programme, Zubehör, Eingabeaufforderung, bitte als "Administrator" ausführen oder [Windows]+[R] -> cmd
