Linux Mint Tipps



Eines gleich vorweg: Wenn Sie Linux und Windows 7 parallel auf einem System einrichten wollen, ist es empfehlenswert,
Windows 7 zuerst zu installieren. Dies aus gutem Grund: Linux-Installationsassistenten erkennen Windows 7
und bauen es in den Boot-Manager ein - umgekehrt überschreibt Windows 7 meistens die Boot-Einträge von Linux.
............................................. Bei mir ist beim Pc Start Esc fürs Bootmenue zu drücken und auf den leeren Platz unterm CD und Festplatte auf den LEEREN Platz zu klicken um von USB zu starten.
............................................ Ein paar Basic's:
1024 MB = 1GB | 1024GB = 1TB | usw.
/dev/sda -> Laufwerk / Festplatte a
/dev/sda -> /dev/sdb -> /dev/sdc -> /dev/sdb -> usw.
Steht eine Zahl dahinter, dann ist es eine Partition:
/dev/sda1 -> Partition 1
Unter Windows -> Laufwerk (C:), Laufwerk (D:), Laufwerk (E:), usw.
Unter Linux -> /dev/sda, /dev/sdb, /dev/sdc, usw.
Windows verwendet NTFS, Linux ext3 oder ext4.
.......................................................... Swap = Auslagerungsspeicher - bei Windows Virtueller Arbeitsspeicher, Auslagerungsdatei.
/swap mindestens so groß wie der verbaute Arbeitsspeicher/Ram.Besser doppelt so groß.
/ Für Linux mint so groß wie gewünscht 250GB.
Für /boot die Festplatte an sich auswählen.
.............................................. Grub-Konfigurationsdatei ändern:
Hintergrundbild im Startmenü. das Bild muß nach /boot/grub sudo cp -v ~/Downloads/boot.jpg /boot/grub grub sich updaten lassen damit er das Bild benutzt. sudo update-grub Bild wieder entfernen mit sudo rm -v /boot/grub/boot.jpg .................................................. Grub einsehen /boot/grub/grub.cfg .......................................... [Strg]+[Alt]+[T] = Terminal
[Strg]+[Alt]+[F7] = Grafische Umgebung
[Tabolatortaste] = Verfolständigt Ordnernamen,Befehle zb. Dow -> Downloads
whoami = Angemeldeter Benutzer
id = Benutzer Informationen,Gruppen...??
pwd = (printworkingdirectory)Wo bin ich, in welchem Verzeichnis zb. ~ = Home
ls = Listet Inhalt des aktuellen Verzeichnisses
ls Downloads / = Zeigt Inhalt von Downloads
ls / = Zeigt den Root Ordner,das Root verzeichniss, das oberste Level des Verzeichnisbaumes
touch Downloads/Test.txt = Erstellt Test.txt in Downloads
ls /home/Benutzer/Downloads/ = Absoluter Pfad, zeigt auch Inhalt von Down.
mkdir Test = (makeDirectory)Erstellt ein Verzeichniss namens Test
cd Test = geht in den Test Ordner,Verzeichniss
cd .. = geht eine Ebene höher, geht wieder aus dem Verzeichniss
cd ../.. = geht 2 Ebenen höher
cd oder cd ~ = Wechselt in das Home Verzeichniss
cd ~/downloads = Geht zu Downloads
rmdir Test = löschen des Verzeichnisses Test
rm -r Test = löschen von Verzeichnissen mit Daten
