# Super Pimmelchen – austauschbare Spielgrafiken

Alle Symbole liegen neben der HTML-Datei in diesem Ordner. Das Spiel lädt sie anhand ihres deutschen Dateinamens und skaliert sie für das Spielfeld. Du kannst eine Grafik ersetzen, indem du die Datei mit demselben Namen austauschst.

| Datei | Bedeutung |
|---|---|
| `futter.svg` | Normales Futterstück |
| `uhr.svg` | 40 Sekunden extra |
| `puck.svg` | Puck-Kopf: Futter einsammeln ohne Wachstum |
| `eiswuerfel.svg` | Halbiert die Körperlänge |
| `frucht.svg` | Bonuspunkte; nach vier Früchten ein Extra-Leben |
| `totenschaedel.svg` | Kostet ein Leben |
| `blitz.svg` | Beendet die aktuelle Stufe |
| `herz.svg` | Extra-Leben |
| `powerdose.svg` | Macht acht Sekunden schneller |
| `elixier-kurz.svg` | Kürzt den Körper um einige Segmente |
| `elixier-leer.svg` | Lässt nur den Kopf übrig |
| `sonne-gross.svg` | Futter wird größer und bringt mehr Wachstum |
| `sonne-klein.svg` | Futter wird kleiner und bringt kein Wachstum |
0 leer
1 Mauer
2 Futter
3 Start punkt
4 erkennt Anfang, Ende, Gerade und Kurve.
5 zeichnet zusätzlich eine Unterführung quer zur Brücke.
Die Symbole sind SVG-Bilder und bleiben beim Skalieren scharf. Für PNG oder JPG kannst du eine Datei ersetzen und den Dateinamen im Asset-Eintrag am Anfang des Spielscripts ändern.
