MEMORY

Decke zwei Karten auf. Passen die Bilder zusammen, bleiben sie offen.

Karte antippen, dann eine zweite – am besten mit gutem Gedächtnis.
Regeln
  1. Ziel: Alle Kartenpaare finden, und zwar in möglichst wenigen Zügen und möglichst schnell.
  2. Züge: Zwei Karten werden aufgedeckt. Passt das Bild, bleiben beide offen – sonst drehen sie sich wieder um.
  3. Größe: 4×3 ist die leichte Stufe (6 Paare), 4×4 hat 8 Paare, 4×5 zehn Paare.
  4. Zeit: Sie läuft ab dem ersten Zug. Die Bestzeit merkt sich der Browser für jede Stufe getrennt.
  5. Tipp: Erst schauen, dann merken – wer die Lage der Karten behält, braucht deutlich weniger Züge.
